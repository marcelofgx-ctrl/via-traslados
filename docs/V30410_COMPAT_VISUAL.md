# V30.4.10 QA — política de compatibilidad visual
Samsung Internet es la referencia visual física del usuario. Mantener su diseño sin overrides. El perfil es una etiqueta de presentación local; no se envía ni persiste ni afecta autenticación, GPS, mapa, reservas o API. Detectar Samsung antes de Chrome, iOS antes de otros motores; distinguir Android WebView, Edge, Opera, Firefox. Los perfiles sin evidencia heredan el diseño base. El primer experimento se limita al glifo GPS de Chrome Android, objetivo 24 CSS px sin modificar el área táctil. No aplicar fuentes distintas, zoom, filtros generales, ni cambios de contraste sin medición. Chrome y Samsung simulados con Chromium no certifican el renderizado físico Samsung/Android; comparar capturas en el mismo dispositivo, tema, zoom y estado. La QA estática no permite reservas; sin DB ni bindings productivos. Base V30.4.9 b23d68ea-5aae-4827-b808-3c4c3504a959. Prohibida promoción automática.
